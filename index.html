关于 C³ System

C³ System — 以循证为本的跨学科疗愈体系

C³ · UNI Healer · 彦旭 (L)

C³ System 创始人，跨学科疗愈设计师，致力于将用户体验设计思维与心理健康实践深度融合。拥有伦敦艺术大学用户体验设计硕士学位和联合国国际疗愈师资格认证，具备从学术研究到项目落地的全链路能力。

C³ System 是一套以循证方法为核心的跨学科疗愈体系，汇聚具有专业资质的疗愈师团队。根据不同项目需求，匹配最合适的疗愈师——涵盖颂钵疗愈、自然疗愈、艺术疗愈、正念冥想等领域，确保每一位服务对象获得专业、有针对性的疗愈支持。

曾在英国首个列入一级保护的后现代主义建筑遗产空间 Cosmic House（宇宙之家），担任文化讲解与体验引导工作，参与Stby Studio全球服务设计工作坊、AXA Health社区孤独干预项目、Glass-House城市空间女性议题共创等国际项目。自主开发潜意识投射卡牌疗愈工具，策划主持心流绘画冥想工作坊，具备丰富的跨文化、跨社群共创经验。
